# KIBERone Card Generator 🚀

Инструмент для создания премиальных карточек-расшифровок занятий международной кибершколы KIBERone.

## 🌟 Возможности
- Генерация стильных JPG-карточек для родителей.
- Премиальный дизайн в стиле Cyberpunk / Tech.
- Экспорт в высоком разрешении (2x).
- Адаптивность (работает на мобильных и ПК).

## 📥 Как пользоваться
1. Откройте [kiberone-card-generator](https://q0wqex.github.io/kiberone-card-generator/) (или файл `index.html` локально).
2. Используйте **[PROMPT.md](./PROMPT.md)** для нейросети, чтобы получить структурированный текст из ваших PDF.
3. Вставьте текст в поля генератора.
4. Нажмите **"СКАЧАТЬ В JPG"**.

## 🛠 Технологии
- HTML5 / CSS3 (Vanilla)
- JavaScript (Vanilla)
- [html-to-image](https://github.com/tsayen/html-to-image)
- [Lucide Icons](https://lucide.dev/)
- [Google Fonts (Inter)](https://fonts.google.com/)
